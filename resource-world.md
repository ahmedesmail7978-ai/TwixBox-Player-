# 🔥 TwixBox Player — Эксклюзивный плеер от by Twixoff

## 📌 Описание
**TwixBox** — это модифицированная версия популярного онлайн-плеера с уникальным дизайном в стиле **Cyberpunk Dark Neon**. Полностью переработанный интерфейс, фиолетово-розовая неоновая палитра, кастомные анимации и полный контроль над источниками.

> ⚡ **Важно:** API и логика работы источников НЕ изменены. Затронут только визуальный стиль (CSS) для создания уникального внешнего вида.

## 🚀 Установка

### Вариант 1: Через iframe
```html
<iframe 
  src="https://bytwixoff.tatnet.app/embed?kinobox=1301710" 
  width="100%" 
  height="450" 
  frameborder="0" 
  allowfullscreen
></iframe>
```

### Вариант 2: Подключение JS API
```html
<div id="player"></div>
<script src="https://bytwixoff.tatnet.app/kinobox.js"></script>
<script>
  kinobox({
    target: document.getElementById('player'),
    props: {
      kinobox: '1301710', // ID фильма
      menu: { enable: true, theme: 'kbt_button' } // kbt_button | kbt_list | kbt_grid | kbt_select
    }
  });
</script>
```

### Вариант 3: Готовый HTML
Скачайте файл `index.html` и разместите на своём хостинге. Все стили и скрипты уже подключены.

## 🎯 Темы меню

| Тема | Описание |
|------|----------|
| `kbt_button` | Модальное окно снизу с кнопками |
| `kbt_list` | Боковое выпадающее меню справа |
| `kbt_grid` | Сетка кнопок (адаптивная) |
| `kbt_select` | Выпадающий список (select) |

Пример смены темы:
```js
menu: { enable: true, theme: 'kbt_grid' }
```

## 🔧 Настройка

### Изменение цвета акцента
Откройте `kinobox.css` и измените переменные:
```css
:root {
  --twix-primary: #a855f7;    /* Основной фиолетовый */
  --twix-secondary: #ec4899;  /* Розовый акцент */
}
```

### Отключение меню
```js
menu: { enable: false }
```

## ❓ FAQ

**Q: Плеер не работает?**  
A: Убедитесь, что подключён `kinobox.js` и правильно указан ID фильма в параметре `kinobox`.

**Q: Можно ли изменить цвета?**  
A: Да, все цвета вынесены в CSS-переменные в начале файла `kinobox.css`.

**Q: Работает ли на мобильных?**  
A: Да, плеер полностью адаптивен и протестирован на iOS/Android.

**Q: API изменилось?**  
A: Нет, вся логика работы источников осталась как в оригинале. Изменён только CSS.
